# Style card: "Power explainer" (the default style)

Studied from the reference reel https://www.instagram.com/reel/Df2Hu67s174/ (vidIQ scene breakdown, 0:44, 9:16).
We copy the **editing grammar only**, never that creator's face, words, topic, logos or graphics.

## The grammar
| Element | Rule |
|---|---|
| Format | 9:16, 1080x1920, 30 fps, 30–45 s |
| Hook | First 2–5 s: one bold claim + one visual card on screen by 0:01 |
| Cuts | A jump cut or punch-in every **1.5–3 s**. Alternate scale 1.00 ↔ 1.10–1.18, focus on the face (focus_y ≈ 0.38–0.42) |
| Captions | **Clean, like the reference (measured by vidIQ):** plain white `#FFF`, medium/semibold (600), NO outline, NO highlight colour, very soft shadow only; whole phrase (2–5 words) appears at once with a hard cut, no animation; one line, ≤ 70% of the width; fixed just below the microphone (≈ 61–63% in the reference; 75% for a seated speaker framed lower). Arabic: IBM Plex Sans Arabic 600, 58 px |
| Top pill | Black capsule at the top, progress text: `Step 1 •○○` → `Step 2 ••○` → `Step 3 •••` → `3 steps •••` |
| Info cards | Dark translucent "glass" rounded cards, thin light border, gold accent title. Pop in (fade + 40 px slide up) exactly when the matching word is spoken |
| Sound | Soft pop on every card entrance; light lo-fi/tech music bed under the voice (~12% volume); optional deeper hit on the big reveal |
| Grade | Natural, clean, slightly warm, moderate contrast |
| Ending | Last 4–5 s: comment-keyword CTA card ("Comment VILLA") + note "Details → your DMs" |

## Real estate translation
| Reel element | Real estate version |
|---|---|
| Bold claim hook | "This villa in North Jeddah costs less than an apartment in …" (only if TRUE, from the user's facts) |
| Funnel/stat graphic | `card`: location title + Price / Land / Bedrooms rows; `stat`: "450 m²" "Land size" |
| Step pill | `Step 1 •○○ Location`, `Step 2 ••○ Inside`, `Step 3 ••• Price` |
| Talking head | The agent to camera, OR drone/AI clips with a voiceover (then zooms are gentle 1.00–1.08) |
| Comment CTA | "Comment VILLA" / "Comment تفاصيل" → details in DMs |

Every number on a card must come from the user's message. If a fact is missing, leave the row out and ask; never invent it.
